# Lab_5

Тема: Двунаправленный список

Реализовать базовые операции для двунаправленного динамического списка.


Структура для узла списка (точка в декартовой системе координат)

struct point {
	int x; // Координата x
	int y; // Координата y
	struct point* prev; // Указатель на предыдущий узел
	struct point* next; // Указатель на следуюий узел
};

Голова списка - указатель на первый узел списка
Хвост списка - последний узел списка

struct point* add_to_head(struct point** list, int x, int y);

(перед первым элементом).
Если список пустой, то добавляет элемент в список и обновляет голову, иначе добавляет в голову обновляет голову, и в любом случае обновляет связи 
Если ошибка добавления, возвращает NULL. Иначе возвращает указатель на добавленный элемент.

Добавление элемента в хвост
struct point* add_to_tail(struct point** list, int x, int y);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову) и данные (координаты x и y) для добавления узла в хвост списка
(после последнего элемента).
Если список пустой, то добавляет элемент в список и обновляет голову, иначе добавляет в хвост и в любом случае обновляет связи
Если ошибка добавления, возвращает NULL. Иначе возвращает указатель на добавленный элемент.

Добавление элемента перед элементом (Поиск элемента по данным)
struct point* add_before_el(struct point** list, int x, int y, int x_add, int y_add);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову), данные элемента, перед которым нужно вставить (координаты x и y),
и данные (координаты x_add и y_add) для добавления узла перед элементом с заданными данными. Если нужный голова, то обновляет голову, иначе ставит перед заданным
и в любом случае обновляет связи. обновляет связи. Если список пустой, или не нашли элемент, то возвращает NULL.
Если ошибка добавления, тоже NULL. Иначе возвращает указатель на добавленный элемент.

Добавление элемента после элемента (Поиск элемента по данным)
struct point* add_after_el(struct point** list, int x, int y, int x_add, int y_add);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову), данные элемента, после которого нужно вставить (координаты x и y),
и данные (координаты x_add и y_add) для добавления узла после элемента с заданными данными. Если нужный хвост, то добавляет элемент в хвост, иначе ставит после заданного
и в любом случае обновляет связи. Если список пустой, или не нашли элемент, то возвращает NULL. Если ошибка добавления, тоже NULL.
Иначе возвращает указатель на добавленный элемент.

Добавление элемента после элемента на k позицию. (Индексация с нуля. Текущий элемент на k поззиции сдвигается вправо)
struct point* add_to_pos(struct point** list, size_t k, int x, int y);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову), номер позиции (k), на которую нужно вставить,
и данные (координаты x и y) для добавления узла на k позицию. Если нужный голова, то обновляет голову. Иначе вставлет на k позицию и обновляет связи
Если список пустой, или не нашли элемент, то возвращает NULL. Если ошибка добавления, тоже NULL. Иначе возвращает указатель на добавленный элемент.

Поиск элемента по данным
struct point* find_el(struct point* list, int x, int y);
Функция получает на вход (указатель) переменню голову (или адрес на первый элемент) и данные элемнта (координаты x и y), который нужно найти, и ищет нужный элемент по
этим данным. Если найден, то возвращает указатель на него, иначе NULL. Если пустой список, тоже NULL.

Удаление головы (первого элемента)
void del_head(struct point** list);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову) и удаляет элемент из головы списка (обновляет связи и голову в обход
этого элемента и очищает память, выделенную для этого элемента). Если список пустой, то ничего не удаляет. По итогу функция ничего не возвращает.

Удаление хвоста (последнего элемента)
void del_tail(struct point** list);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову) и удаляет элемент из хвоста списка (обновляет связи в обход него и
очищает память, выделенную для этого элемента). Если в списке только один элемент, то обновляет голову и также очищает память.
Если список пустой, то ничего не удаляет. По итогу функция ничего не возвращает.

Удаление элемента (Поиск элемента по данным)
void del_el(struct point** list, int x, int y);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову), и данные, для поиска нужного элемента,
и удаляет этот элемент из списка (обновляет связи в обход него и очищает память, выделенную для этого элемента).
Если в списке только один элемент, то обновляет голову и также очищает память. Если хвост, то тоже обновляет связи, которые нужно, и очищает память. 
Если список пустой, то ничего не удаляет. По итогу функция ничего не возвращает.

Удаление элемента на k позиции (Индексация с нуля. Элемент с k+1 позиции сдвигается влево)
void del_at_pos(struct point** list, size_t k);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову), и номер позиции (k), с которой нужно удалить,
и удаляет этот элемент из списка (обновляет связи в обход него и очищает память, выделенную для этого элемента).
Если в списке только один элемент, то обновляет голову и также очищает память. Если хвост, то тоже обновляет связи, которые нужно, и очищает память. 
Если список пустой, то ничего не удаляет. По итогу функция ничего не возвращает.

Удаление всего списка (очищение всей памяти из под всех узлов)
void clear_list(struct point** list);
Функция получает на вход адрес переменной головы (или двойной указатель на (указатель) переменную голову) и удаляет из головы функцией del_head() все элементы,
пока список не пустой. По итогу функция ничего не возвращает.

Удаление всего списка (очищение всей памяти из под всех узлов)
void print_list(struct point* list);
Функция получает на вход (указатель) переменню голову (или адрес на первый элемент) и выводит все элементы в формате:
"N = %2zu, x = %2d, y = %2d   ||   adress = %p, prev = %p, next = %p\n" 
N - индекс элемента, x - координата x, y - координата y, adress - адрес элемента, prev - адрес предыдущего за ним элемента, next - адрес следующего за ним элемент
По итогу функция ничего не возвращает.
